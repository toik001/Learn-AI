pi-mono 七篇专题实施计划

Agent 执行要求：实施时使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans，逐任务执行并使用复选项跟踪；当前仓库禁止新增 Markdown 学习笔记，因此本计划使用 HTML。

目标：创建七篇互链的 pi-mono 中文专题，让开发者能理解设计理念与源码架构、完成安装使用与扩展开发，并与五个主流编码 Agent 做基于一手资料的选型比较。

架构：七篇静态 HTML 位于同一 coding-agent 分类，共用现有 CSS、JavaScript、根索引生成器和站点验证器。每篇承担单一主题，通过显式专题导航连接；一个 Node.js 契约测试支持按页面执行，以便每个写作任务都能独立验证，最后再运行全专题互链与全站检查。

技术栈：HTML5、共享 CSS、原生 JavaScript/Node.js 测试、TypeScript/Node.js 示例、GitHub Pages branch 部署。

全局约束

  • 恰好新增七篇学习页，统一位于 public/notes/coding-agent/，日期固定为 2026-08-10。
  • 源码与扩展示例保持 Pi 原生的 TypeScript、JavaScript 和 Node.js 技术语境，不增加 Java、Spring Boot 或其他特定后端语言视角。
  • 每篇包含 header、nav、main、article、完整元数据、“核心结论”和“参考资料”；所有 h2～h4 使用唯一稳定 ID。
  • 外部资料检索日期为 2026-08-10；关键版本、许可证、功能与扩展边界必须来自官方仓库、官方文档或发布说明。
  • 外链使用 target="_blank" 和 rel="noopener noreferrer"；站内链接保持相对路径，适配 /Learn-AI/ 项目子路径。
  • 图表只使用语义化 HTML/CSS 与等价文字说明，不加入第三方前端依赖、远程图片或 Mermaid 运行时。
  • 明确标注“官方说明”“仓库观察”“选型建议”；不声称对外部认证、付费模型或云端服务完成了未执行的端到端实测。
  • 比较对象固定为 Claude Code、Codex CLI、OpenCode、Aider、Goose；不建立缺乏可复现实验的性能排名或综合分数。

文件结构

  • scripts/test-pi-mono-series.mjs：按页面键或全量验证七篇页面的结构、章节、关键事实标签、来源、互链和技术边界。
  • public/notes/coding-agent/2026-08-10-Pi项目总览与学习路线.html：能力地图、学习路线、定位与术语。
  • public/notes/coding-agent/2026-08-10-Pi设计理念与边界.html：设计原则、取舍、适用边界和误区。
  • public/notes/coding-agent/2026-08-10-Pi源码架构与运行机制.html：monorepo package、请求路径、Agent Loop、事件和会话。
  • public/notes/coding-agent/2026-08-10-Pi安装配置与使用教程.html：安装、认证、模型、项目上下文、会话、命令与排错。
  • public/notes/coding-agent/2026-08-10-Pi扩展开发与系统集成.html：Extension、工具、Prompt、Skill、SDK、RPC 与集成边界。
  • public/notes/coding-agent/2026-08-10-Pi与主流编码Agent对比.html：六项目统一维度事实矩阵与场景比较。
  • public/notes/coding-agent/2026-08-10-Pi选型建议与实践路线.html：决策树、风险清单、分阶段练习和验收。
  • index.html、public/manifest.json与所有知识页导航：由 scripts/build-html-index.mjs 统一生成更新。
