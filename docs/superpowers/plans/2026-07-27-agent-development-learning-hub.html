Agent 开发主学习目录实现计划

Agent 执行要求： 实现时必须逐项使用 superpowers:subagent-driven-development（推荐） 或 superpowers:executing-plans。

目标：创建一个面向 Java 开发者、厂商无关的 Agent 开发主学习入口，并把它接入现有静态知识库。

架构： 正文使用单个语义化 HTML 页面；调用链和学习路线由语义化元素配合共享 CSS 呈现， 不引入第三方运行时或内联 SVG。现有索引脚本负责首页卡片、侧栏、上一篇/下一篇和 manifest。

技术栈：HTML5、CSS、现有原生 JavaScript、Node.js 索引脚本、Java 21 示例。

全局约束

  • 正式页面路径固定为 public/notes/agent/2026-07-27-Agent开发学习主目录.html。
  • 分类固定为“Agent 开发”，整理日期固定为 2026-07-27。
  • 页面复用 ../../assets/style.css 和 ../../assets/app.js。
  • 内容采用厂商无关定义；Java 示例使用 Java 21，不引入 SDK 依赖。
  • 图示使用 HTML/CSS，并提供等价文字说明；不使用内联 SVG。
  • 未创建的专题显示“待建设”，不得生成失效链接。
  • 外部来源只使用一手资料，链接带 target="_blank" 和 rel="noopener noreferrer"。

任务 1：创建可独立阅读的 Agent 主学习页面

文件：新建 public/notes/agent/2026-07-27-Agent开发学习主目录.html

输入：现有文档页面结构、共享样式和确认后的设计规格。
输出：包含完整目录、定义、调用过程、Java 映射、代码、学习路径、练习和参考资料的语义化页面。

  1. 先运行存在性检查，确认测试失败：

    test -f public/notes/agent/2026-07-27-Agent开发学习主目录.html

    预期：退出码非 0，因为页面尚未创建。

  2. 创建页面骨架：

    • head 中包含 charset、viewport、description、color-scheme、study-category、study-date、title、共享 CSS 和 JS。
    • body 使用 document-page，包含 topbar、reader-layout、doc-sidebar、article-column、article 和 toc-sidebar。
    • 页内目录包含以下稳定锚点：核心结论、agent-通用释义、agent-不是什么、核心组成、一次完整调用过程、java-开发者映射、最小-java-实现、主学习路线、第一个实践项目、参考资料。

  3. 写入定义与边界：

    • Software Agent：感知环境、依据规则或策略采取行动以实现目标的软件实体。
    • AI Agent：决策策略部分使用机器学习或生成式模型的 Agent。
    • LLM Agent：以大语言模型承担理解、推理、规划或工具选择的 AI Agent。
    • Agentic System：由一个或多个 Agent、工具、状态、控制逻辑与人类协作组成的完整系统。
    • 用表格比较普通聊天机器人、固定工作流、单 Agent 和多 Agent 系统的控制方式、工具使用、状态和适用场景。

  4. 写入调用链：

    图中必须依次出现“用户目标、上下文组装、模型决策、工具调用、环境反馈、状态更新、循环判断、最终响应”，并将权限、校验、预算、人工审批和失败降级放入护栏层。

    逐步文字说明明确两种分支：模型直接产生最终答案；模型请求工具后根据 Observation 继续循环。循环必须受最大步数、超时和成本预算约束。

  5. 写入 Java 映射和最小代码：

    示例定义 AgentModel、ToolRegistry、AgentState、ModelDecision 和 AgentRuntime.run(AgentRequest)，用最大 8 步循环展示结构化工具调用、状态更新和终止条件。所有泛型尖括号必须经过 HTML 转义。

  6. 写入八阶段学习路线：

    每阶段同时列出学习目标、关键问题、Java 实践和验收标准。未建设专题用非链接状态标签显示。

  7. 写入练习和参考资料：

    练习为“带白名单城市与超时控制的天气工具 Agent”；验收包括结构化参数、工具白名单、最多 8 步、可追踪调用记录、错误降级和单元测试。

    参考资料使用 Agent 定义、ReAct/Tool Use 原始论文或官方说明，以及 Spring AI、LangChain4j 的官方文档，并记录 2026-07-27 检索日期。

  8. 验证页面存在且元数据完整：

  4. 运行本地链接与标题锚点检查：

    node - <<'NODE'
const fs = require("fs");
const path = require("path");
const root = path.resolve("public");
const files = [];
function walk(dir) {
  for (const entry of fs.readdirSync(dir, {withFileTypes: true})) {
    const target = path.join(dir, entry.name);
    if (entry.isDirectory()) walk(target);
    else if (entry.name.endsWith(".html")) files.push(target);
  }
}
walk(root);
const errors = [];
for (const file of files) {
  const html = fs.readFileSync(file, "utf8");
  const ids = new Set([...html.matchAll(/\sid=["']([^"']+)["']/g)].map(match => match[1]));
  for (const match of html.matchAll(/href=["']([^"']+)["']/g)) {
    const href = match[1];
    if (/^(https?:|mailto:|javascript:)/.test(href)) continue;
    const [rawPath, hash] = href.split("#");
    const target = rawPath ? path.resolve(path.dirname(file), rawPath) : file;
    if (rawPath && !fs.existsSync(target)) errors.push(`${file}: missing ${href}`);
    if (hash && target === file && !ids.has(decodeURIComponent(hash))) errors.push(`${file}: missing #${hash}`);
  }
}
if (errors.length) {
  console.error(errors.join("\n"));
  process.exit(1);
}
console.log(`checked ${files.length} HTML files`);
NODE

    预期：输出检查到的 HTML 文件数量，退出码为 0。
