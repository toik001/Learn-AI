Agent 开发八阶段课程实施计划

Agent 执行要求： 必须使用 superpowers:subagent-driven-development 逐任务实施， 每个专题完成后执行规格与质量审查。

目标：建设八篇 Agent 专题学习页，将主目录升级为完整的 Java 21 + Spring AI 渐进课程。

架构： 每个专题是独立 HTML 内容单元，使用统一页面外壳、共享样式和企业服务台案例。 前八个任务分别创建页面；第九个任务建立课程互链并更新主目录； 第十个任务运行索引生成和全站回归验证。

技术栈： HTML5、共享 CSS、现有原生 JavaScript、Java 21、Spring Boot 4.0/4.1、 Spring AI 2.0.0、Maven BOM、Micrometer/OpenTelemetry。

全局约束

  • 八个页面固定使用设计规格中列出的路径，分类统一为“Agent 开发”，整理日期为 2026-07-27。
  • 每篇使用 ../../assets/style.css 和 ../../assets/app.js，遵循现有 document-page 外壳。
  • Java 核心示例使用 Java 21；Spring AI 示例锁定稳定版 2.0.0，兼容 Spring Boot 4.0.x 或 4.1.x。
  • 依赖管理使用 org.springframework.ai:spring-ai-bom:2.0.0，不使用 SNAPSHOT 或里程碑版本。
  • 示例不绑定具体模型厂商；需要模型 Bean 时使用 ChatModel、EmbeddingModel 等抽象。
  • Spring AI 原生能力与业务自建能力必须明确标注，不把 Planner、Coordinator、审批或恢复队列描述为框架原生组件。
  • 每篇包含核心结论、页内目录、至少一个语义化 HTML/CSS 图示、Java 21 示例、Spring AI 示例、练习、验收标准和参考资料。
  • 模型输出、检索文本和工具 Observation 均按不可信输入处理；公开错误与私有诊断分离。
  • 联网资料只使用论文原文、标准组织、Spring 官方文档、官方项目文档或源代码仓库，并标记检索日期 2026-07-27。
  • 外链必须使用 target="_blank" 和 rel="noopener noreferrer"；Java 泛型与 Lambda 箭头必须 HTML 转义。
  • 专题创建阶段不链接尚未创建的页面；课程互链统一由任务 9 添加。

已核验的 Spring AI 基线

以下官方资料检索于 2026-07-27，所有专题应按需就近引用：

  • Getting Started：Spring AI 2.0.0 BOM，支持 Spring Boot 4.0.x/4.1.x。
  • ChatClient：同步/流式调用与 Advisor 接入。
  • Advisors API：请求/响应拦截、上下文和内置 Advisor。
  • Tool Calling：2.0 的 ToolCallingAdvisor、框架控制、Advisor 控制和用户控制三种生命周期。
  • Structured Output：POJO 转换与原生结构化输出。
  • Recursive Advisors：StructuredOutputValidationAdvisor 与 ToolCallingAdvisor。
  • Chat Memory：ChatMemory、ChatMemoryRepository、MessageChatMemoryAdvisor 和会话 ID 约束。
  • VectorStore：VectorStoreRetriever、VectorStore 和 SearchRequest。
  • RAG：VectorStoreDocumentRetriever 与模块化 RAG。
  • ETL Pipeline：DocumentReader、DocumentTransformer 和 DocumentWriter。
  • Observability：ChatClient、Advisor、ChatModel、工具和 VectorStore 指标/Trace；工具参数与结果默认不导出。
