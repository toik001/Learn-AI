Agentic Search 与 RAG 学习页实施计划

执行要求：实施时使用 superpowers:executing-plans，逐项完成并验证。

目标：新增一篇能指导 Java 开发者理解、选型并实现 Agentic Search 的完整 HTML 学习页。

架构：用独立进阶页承载概念、对比和实现；从 Agent 主目录与 RAG 基础课交叉链接；由现有生成器统一更新分类导航、右侧目录、前后篇和 manifest。

技术栈：语义化 HTML、现有 CSS/JavaScript、Java 21、Spring Boot 4.0.x/4.1.x、Spring AI 2.0.0、Node.js ESM 验证脚本。

全局约束

  • 学习内容只写入 HTML，不新增 Markdown。
  • 所有站内链接使用相对路径；所有外链带 target="_blank" 和 rel="noopener noreferrer"。
  • 把“Agentic Search 非统一标准术语”明确标为基于一手资料的工程归纳。
  • 示例不假设 Spring AI 提供名为 Agentic Search 的单一抽象；由应用代码显式管理循环与边界。
  • 不得覆盖或重构无关页面内容。
