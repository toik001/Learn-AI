知识库分类导航优化实施计划

目标：生成分类内聚的左侧导航、以大分类为第一入口的首页，以及可自然换行的统一右侧目录。

架构：由 build-html-index.mjs 统一生成结构，CSS 负责布局和换行，现有 JavaScript 继续负责搜索、移动侧栏和目录高亮。

技术栈：Node.js ESM、语义化 HTML、原生 CSS、原生 JavaScript。

全局约束

  • 页面分类只读取 study-category 或现有 fallback。
  • 所有 URL 保持相对路径，兼容 GitLab Pages 子路径部署。
  • 不引入构建框架、前端依赖或 Markdown 内容源。
  • 生成器重复运行除 manifest.generatedAt 外必须幂等。

任务一：建立真实生成器回归测试

创建：scripts/test-html-navigation.mjs

  1. 复制当前 public 和生成器到系统临时目录。
  2. 运行真实生成器并解析输出，而不是检查源代码文本。
  3. 断言左侧只含当前分类文档、只有一个活动项，并包含首页及分类入口。
  4. 断言首页分类入口数量等于唯一分类数量，每个锚点实际存在。
  5. 断言右侧目录统一为 ol.toc-list，目录链接目标存在。
  6. 先运行并观察当前实现因跨分类侧栏、缺少分类入口和不统一目录而失败。

任务二：生成分类侧栏与统一目录

修改：scripts/build-html-index.mjs

  1. 新增稳定分类锚点函数，将分类名编码为确定性 ID。
  2. documentNavigation 只接收当前分类文档，并给活动项添加 aria-current="page"。
  3. 新增侧栏头部生成函数，输出知识库首页、当前分类入口、分类名和文档数。
  4. 新增 tableOfContents，根据正文 h2～h4 输出统一列表；没有标题时输出空状态。
  5. updateDocumentHtml 替换现有左侧导航和右侧目录，不改文章正文。
  6. 运行回归测试，确认生成结构通过。

任务三：首页大分类入口

修改：scripts/build-html-index.mjs、public/assets/app.js

  1. 在首页搜索区之后生成 category-entry-grid，每张卡显示文档数和章节数。
  2. 为每个分类文档区添加稳定 ID，入口卡链接至该 ID。
  3. 保留现有文档卡和全库搜索；分类入口卡不参与文档匹配计数。
  4. 运行测试，确认分类卡与区块一一对应，搜索行为没有回归。
