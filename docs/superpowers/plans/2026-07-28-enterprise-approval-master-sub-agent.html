企业智能审批与公司主子 Agent 落地实战实施计划

目标：新增一篇面向 Java 开发者的企业智能审批实战页，解释公司主/子 Agent 的真实应用边界，并把它接入现有 Agent 学习路线。

架构：以确定性 BPMN/DMN + 受限主 Agent + 专业子 Agent + 人工审批 + 业务系统执行组成闭环。HTML 是唯一内容真相源，生成器负责入口、分类侧栏、目录、pager 与 manifest。

技术：语义化 HTML、共享 CSS/JS、Java 21、Spring AI 2.0.x 概念接口、BPMN/DMN（Camunda 作为示例）、Node.js 内容与导航测试。

全局约束

  • 页面路径固定为 public/notes/agent/2026-07-28-企业智能审批与公司主子Agent落地实战.html。
  • 分类固定为“Agent 开发”，日期固定为 2026-07-28。
  • 必须明确：模型和 Agent 无最终审批权，工作流/规则/授权人拥有最终决定。
  • 所有工具执行前由服务器可信身份重新鉴权；任何写操作都使用提案 hash、审批引用和幂等键。
  • 官方资料只使用一手来源并记录检索日期。
