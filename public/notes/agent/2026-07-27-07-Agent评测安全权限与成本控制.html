#Agent 评测、安全、权限与成本控制

Agent 的验收对象不是最后一句回答，而是“输入与权限上下文 → 模型决策 → 检索与工具 → 审批 → 副作用 → 最终结果”的完整轨迹。质量、安全、延迟和成本必须在同一发布门里共同判定。

#核心结论

  • 评测完整轨迹，而不只评最后答案。一个答案即使措辞正确，只要使用了错误工具、跨租户取数、浪费十次模型调用、缺少证据或偷偷执行写操作，整次运行仍应失败。
  • 确定性检查优先，模型评审只是补充。Schema、引用存在性、授权、预算、tenant、工具次数和副作用可用代码判定；语义完整性可用盲法人工或模型评审，但必须校准、记录评审版本并抽样复核。
  • 安全控制必须位于模型之外。Prompt 不是权限系统。RBAC 提供角色基线，ABAC 与上下文策略绑定主体、资源、tenant、动作、风险、时间和审批；工具 callback 必须在 delegate 执行前再次授权。
  • 不可逆动作先形成提案，再由人决定。建单、发信、删改数据、付款、部署和重启等动作需要绑定具体参数、版本、风险与时效的审批。模型不能批准自己的提案，提案变化会使旧审批失效。
  • 预算是并发安全的执行权限。timeout、输入/输出 token、工具次数、模型调用次数和成本都要在调用前原子预占，在结果后结算；预算耗尽应安全停止或转人工，不能让后台幽灵任务继续消耗。
  • 指标标签必须有界，内容默认不导出。运行 ID、tenant、用户、Prompt、检索文本、工具参数和结果不得成为指标标签。Spring AI 官方配置 spring.ai.tools.observations.include-content 默认为 false；本文显式保持关闭。
  • 框架只提供集成点。Spring AI Advisor 与 Observability 能拦截和观测调用，但评测集、策略、审批、不可变审计、预算、发布门和组织责任仍由应用与组织实现。NIST AI RMF 的 Govern、Map、Measure、Manage 是持续风险闭环，不是一次勾选清单。NIST AI RMF Core

#权限、审批与不可变审计

RBAC + ABAC + 上下文策略

层负责什么服务台示例不能单独解决
RBAC给角色定义粗粒度能力基线访客只读公开状态；一线支持可读本租户工单；审批人可批准有限类别同角色对不同 tenant、资源和时段的差异
ABAC用主体、资源、动作和环境属性判定principal.tenant == ticket.tenant 且 service 在负责范围内风险、执行历史和预算等动态流程状态
上下文策略加入风险等级、来源、审批、运行状态、预算、目的和时间生产重启必须在变更窗、已有具体审批、提案 hash 未变且预算充足身份认证、存储隔离和审计基础设施本身
  1. 入口：从认证中间件得到 principal、tenant、角色和会话强度；用户文本中的同名字段永不覆盖可信上下文。
  2. 模型调用前：Advisor 对本次目的、风险层、模型能力和预算做策略门；拒绝时不进入模型。
  3. 工具暴露：每次请求只注册当前用例需要的 callback；工具名清单不是授权结果。
  4. 工具执行前：callback wrapper 用真实工具名、服务器上下文、规范化参数摘要和资源属性再次授权；先预占预算，后调用 delegate。
  5. 不可逆动作：先生成无副作用提案，规范化后计算 hash；批准绑定已认证审批人、提案 hash、策略版本和过期时间。修改任何字段都必须重新审批。
  6. 外部副作用：受控 writer 使用独立最小权限身份和幂等键；超时后先查询结果，不盲目重放。

不可变审计与最小披露

不可变不是“数据库列不提供 update 按钮”，而是只追加、受访问控制、带序号 / 前序摘要、保留策略和外部完整性验证；更新与删除应产生新的纠正 / 保留事件。审计至少关联 run、actor、tenant 的不可逆标识、动作类别、资源引用、策略 / 预算决定原因码、审批引用、外部结果引用和 trace ID。默认不保存 Prompt、检索正文、工具参数 / 结果、凭证、个人数据或异常原文；确需取证内容时进入独立加密证据库，使用单独授权、短 TTL 和访问审计。

审计中允许的安全字段默认禁止字段替代方式
opaque run / event / actor / resource ref，tenant hash，动作枚举，策略版本，原因码，用量计数，时间，前序摘要用户原文、Prompt、检索片段、工具 arguments / result、API key、Cookie、Authorization header、异常堆栈分类码、长度 / 数量、内容摘要 hash、受限证据引用和公开错误码

#成本与执行预算

预算必须同时覆盖绝对 deadline、输入 token、输出 token、工具调用、模型调用和货币成本。预算上限来自组织风险与产品 SLO，不来自模型建议。调用前以最坏合理估计做原子预占，调用后按供应商用量和版本化价目表结算；失败调用、重试、评审和并行分支都计费。

预算调用前检查运行中 / 结束后耗尽行为
时间 / timeout剩余时间是否覆盖下游 timeout + 清理余量传播同一绝对 deadline；取消模型、HTTP、数据库和子任务停止新调用，取消在途，返回部分结果或转人工
输入 / 输出 token预估上下文 + max output；不只看当前消息按实际 usage 结算，记录缓存 token裁剪不改变授权 / 证据语义时才裁剪，否则拒绝或升级
工具次数按工具风险与调用上限原子预占重复、失败和超时均计入尝试；副作用用独立幂等不换别名绕过，不让模型继续“试一个工具”
模型调用次数规划、执行、反思、评审和摘要统一计数检测无进展与递归委派直接结束或进入人工队列
成本按模型 / 工具价目版本估算最坏增量用整数微单位结算；归集成功与失败硬门拒绝；不得在异常路径静默超支

指标建议：cost_per_success = total_run_cost / successful_runs，同时报告失败运行成本；trajectory_efficiency = required_progress_events / all_model_and_tool_events 只作为诊断，不能用增加“进展事件”的方式刷分。p95 与成本门应按风险层和用例分组，tenant / user / run ID 不进入 meter 标签。

interface AtomicBudgetLedger {
    // 实现必须用数据库条件更新 / CAS；不能“先读剩余、稍后再减”。
    BudgetDecision tryReserve(

    void settle(String runId, UUID reservationId, UsageDelta actual);

final class GovernedToolUse {
    private final ToolPolicy policy;
    private final AtomicBudgetLedger budgets;
    private final AppendOnlyAuditStore audit;
    private final ToolExecutor executor;

    ToolResult execute(TrustedRunContext context, ToolProposal proposal) {
        PolicyDecision policyDecision =
                policy.authorize(context, proposal.normalizedMetadata());
        auditPolicyDecision(context, proposal, policyDecision);

        if (!policyDecision.allowedToExecute()) {
            throw new SafeDenialException("Action not permitted");
        }

        BudgetDecision budgetDecision = budgets.tryReserve(
                context.runId(), context.clock().instant(),
                proposal.worstCaseUsage());
        if (budgetDecision instanceof BudgetDecision.Denied denied) {
            auditBudgetDenial(context, proposal, denied.reasonCode());
            throw new SafeDenialException("Execution budget exhausted");
        }

        var reservation = (BudgetDecision.Reserved) budgetDecision;
        try {
            ToolResult result = executor.execute(
                    proposal.withAbsoluteDeadline(context.deadline()));
            budgets.settle(
                    context.runId(), reservation.reservationId(), result.usage());
            return result;
        }
        catch (RuntimeException failure) {
            // 失败尝试也结算；私有诊断只存受限引用，不放入公开错误或审计 payload。
            budgets.settle(
                    context.runId(), reservation.reservationId(),
                    proposal.failureUsageEstimate());
            throw failure;
        }
    }

    private void auditPolicyDecision(
            TrustedRunContext context,
            ToolProposal proposal,
            PolicyDecision decision) {
        // 省略摘要链生成；payload 仅放 opaque ref、原因码和计数。
    }

    private void auditBudgetDenial(
            TrustedRunContext context,
            ToolProposal proposal,
            BudgetReasonCode reason) {
        // 审计失败必须让高风险执行安全失败，不能“先执行，稍后补日志”。
    }
}

顺序不可交换：先授权、再原子预占、再执行；拒绝时下游调用次数必须为零。若审计是强制控制的一部分，高风险路径必须在可确认的 append 成功后执行；审计不可用时返回 AUDIT_UNAVAILABLE 并安全停止。预算 reservation 失败不能通过并行、换模型或换工具名重试绕过。

interface DownstreamDeadlineController {
    // 实现必须把剩余时间写入真实 provider HTTP 请求，并在到期时取消连接 / Future；
    // 不能只依赖线程 interrupt。工具适配器同样把 deadline 传给 HTTP / DB client。
    <T> T callModel(
            Instant absoluteDeadline,
            ExecutionIntentRef intent,
            java.util.function.Supplier<T> call);
    ToolTransportOutcome callTool(
            Instant absoluteDeadline,
            ExecutionIntentRef intent,
            ToolCallback delegate,
            String toolInput,
            ToolContext toolContext);
}

final class TransportDeadlineController
        implements DownstreamDeadlineController {
    private final ProviderHttpDeadlineBridge modelHttp;
    private final ToolTransportRegistry toolTransports;

    TransportDeadlineController(
            ProviderHttpDeadlineBridge modelHttp,
            ToolTransportRegistry toolTransports) {
        this.modelHttp = modelHttp;
        this.toolTransports = toolTransports;
    }

    @Override
    public <T> T callModel(
            Instant deadline,
            ExecutionIntentRef intent,
            java.util.function.Supplier<T> call) {
        // bridge 的 HTTP interceptor 设置每请求 connect/read timeout，
        // 到期主动关闭连接 / 取消 SDK Future，再由调用抛 ModelTimeoutException。
        return modelHttp.callWithAbsoluteDeadline(
                deadline, intent.idempotencyRef(), call);
    }

    @Override
    public ToolTransportOutcome callTool(
            Instant deadline,
            ExecutionIntentRef intent,
            ToolCallback delegate,
            String toolInput,
            ToolContext toolContext) {
        // registry 只接受已注册的 deadline-aware adapter；它把绝对 deadline
        // 传给真实 HTTP / DB / queue client，而不是在线程外套一个超时 Future。
        return toolTransports.require(delegate).callWithAbsoluteDeadline(
                deadline, intent.idempotencyRef(), toolInput, toolContext);
    }
}

final class GovernanceAdvisor implements CallAdvisor {
    static final String TRUSTED_CONTEXT_REF = "app.trusted-context-ref";

    private final TrustedContextStore contexts;
    private final ModelCallPolicy policy;
    private final AtomicBudgetLedger budgets;
    private final AppendOnlyAuditStore audit;
    private final ExecutionIntentLedger intents;
    private final DownstreamDeadlineController deadlines;
    private final OutcomeReconciler reconciler;
    private final ObservationRegistry observations;

    GovernanceAdvisor(
            TrustedContextStore contexts,
            ModelCallPolicy policy,
            AtomicBudgetLedger budgets,
            AppendOnlyAuditStore audit,
            ExecutionIntentLedger intents,
            DownstreamDeadlineController deadlines,
            OutcomeReconciler reconciler,
            ObservationRegistry observations) {
        this.contexts = contexts;
        this.policy = policy;
        this.budgets = budgets;
        this.audit = audit;
        this.intents = intents;
        this.deadlines = deadlines;
        this.reconciler = reconciler;
        this.observations = observations;
    }

    @Override
    public String getName() {
        return "service-desk-governance";
    }

    @Override
    public int getOrder() {
        return Ordered.HIGHEST_PRECEDENCE + 100;
    }

    @Override
    public ChatClientResponse adviseCall(
            ChatClientRequest request, CallAdvisorChain chain) {
        String opaqueRef = requireOpaqueRef(request.context());
        TrustedRunContext context = contexts.requireBoundToCurrentPrincipal(opaqueRef);
        PolicyDecision decision = policy.authorizeModelCall(context);

        appendDecisionOrFailClosed(context, decision);
        if (!decision.allowedToExecute()) {
            throw new SafeDenialException("Request not permitted");
        }
        context.requireTimeForModelCall(); // 校验绝对 deadline 与清理余量。

        BudgetDecision budget = budgets.tryReserve(
                context.runId(),
                context.clock().instant(),
                context.modelCallWorstCaseUsage());
        if (budget instanceof BudgetDecision.Denied denied) {
            // 先追加仅含固定原因码的 BUDGET_DECIDED；失败则 fail-closed。
            appendBudgetDecisionOrFailClosed(context, denied);
            throw new SafeDenialException("Execution budget exhausted");
        }

        BudgetDecision.Reserved reservation =
                (BudgetDecision.Reserved) budget;
        try {
            appendBudgetDecisionOrFailClosed(context, reservation);
        }
        catch (AuditUnavailableException auditFailure) {
            // 模型尚未调用，幂等关闭零消费 reservation。
            budgets.settle(
                    context.runId(), reservation.reservationId(), UsageDelta.ZERO);
            throw auditFailure;
        }

        ExecutionIntentRef intent;
        try {
            intent = intents.appendBeforeExecution(
                    context.runId(),
                    context.modelActionRef(),
                    context.modelIdempotencyRef());
            appendExecutionIntentOrFailClosed(context, intent);
        }
        catch (RuntimeException preExecutionPersistenceFailure) {
            budgets.settle(
                    context.runId(),
                    reservation.reservationId(),
                    UsageDelta.ZERO);
            throw new AuditUnavailableException(
                    "Model execution intent unavailable",
                    preExecutionPersistenceFailure);
        }

        // 若供应商没有返回 usage，保守按 reservation 结算，绝不按零释放。
        UsageDelta actual = reservation.reserved();
        try {
            ChatClientResponse response =
                    Observation.createNotStarted("agent.governance", observations)
                            // 只有有界枚举进入低基数标签；不放 run / user / tenant / prompt。
                            .lowCardinalityKeyValue("agent.operation", "model_call")
                            .lowCardinalityKeyValue(
                                    "agent.risk_tier",
                                    context.riskTier().metricValue())
                            .lowCardinalityKeyValue(
                                    "agent.policy.outcome",
                                    decision.effect().name())
                            .observe(() -> deadlines.callModel(
                                    context.deadline(),
                                    intent,
                                    () -> chain.nextCall(request)));
            actual = ModelUsageExtractor.actualOrReserved(
                    response, reservation.reserved());
            recordModelTerminalOrIndeterminate(
                    context, intent, reservation,
                    IntentState.SUCCEEDED, "SUCCESS", actual);
            return response;
        }
        catch (IndeterminateModelOutcomeException indeterminate) {
            throw indeterminate;
        }
        catch (ModelTimeoutException timeout) {
            actual = ModelUsageExtractor.timeoutOrReserved(
                    timeout, reservation.reserved());
            recordModelTerminalOrIndeterminate(
                    context, intent, reservation,
                    IntentState.TIMED_OUT, "TIMEOUT", actual);
            throw timeout;
        }
        catch (RuntimeException failure) {
            actual = ModelUsageExtractor.failureOrReserved(
                    failure, reservation.reserved());
            recordModelTerminalOrIndeterminate(
                    context, intent, reservation,
                    IntentState.FAILED, "FAILED", actual);
            throw failure;
        }
        finally {
            // success / failure / timeout 恰好走一个 finally；settle 可幂等重试。
            budgets.settle(
                    context.runId(), reservation.reservationId(), actual);
        }
    }

    private String requireOpaqueRef(Map<String, Object> context) {
        Object value = context.get(TRUSTED_CONTEXT_REF);
        if (!(value instanceof String ref) || ref.isBlank()) {
            throw new SafeDenialException("Trusted context missing");
        }
        return ref;
    }

    private void appendDecisionOrFailClosed(
            TrustedRunContext context, PolicyDecision decision) {
        // 生成 SafeAuditPayload；append 失败向上抛出，模型调用次数保持为 0。
    }

    private void appendBudgetDecisionOrFailClosed(
            TrustedRunContext context, BudgetDecision decision) {
        // AuditAction.BUDGET_DECIDED + 固定原因码 / reservation ref；无 prompt。
    }

    private void appendExecutionIntentOrFailClosed(
            TrustedRunContext context, ExecutionIntentRef intent) {
        // EXECUTION_INTENT_RECORDED；只含 model / intent / idempotency ref。
    }

    private void recordModelTerminalOrIndeterminate(
            TrustedRunContext context,
            ExecutionIntentRef intent,
            BudgetDecision.Reserved reservation,
            IntentState terminalState,
            String outcomeCode,
            UsageDelta usage) {
        try {
            appendModelOutcomeOrFailClosed(context, outcomeCode, usage);
            intents.mark(intent, terminalState, outcomeCode);
        }
        catch (RuntimeException terminalPersistenceFailure) {
            try {
                intents.mark(
                        intent, IntentState.INDETERMINATE,
                        "TERMINAL_PERSISTENCE_UNAVAILABLE");
            }
            catch (RuntimeException markUnavailable) {
                // PREPARED intent 由 age-based sweeper 对账。
            }
            try {
                reconciler.enqueueModel(
                        intent,
                        reservation.reservationId(),
                        "TERMINAL_PERSISTENCE_UNAVAILABLE");
            }
            catch (RuntimeException queueUnavailable) {
                // PREPARED intent 仍是恢复依据；禁止重新发起模型调用。
            }
            throw new IndeterminateModelOutcomeException(
                    "Model outcome requires reconciliation",
                    terminalPersistenceFailure);
        }
    }

    private void appendModelOutcomeOrFailClosed(
            TrustedRunContext context, String outcomeCode, UsageDelta usage) {
        // 安全 TrajectoryEvent：仅 outcome、usage、model ref，不含回复正文。
    }
}

import org.springframework.ai.chat.model.ToolContext;
import org.springframework.ai.tool.ToolCallback;
import org.springframework.ai.tool.definition.ToolDefinition;
import org.springframework.ai.tool.execution.ToolExecutionException;
import org.springframework.ai.tool.metadata.ToolMetadata;

final class PreauthorizedToolCallback implements ToolCallback {
    private static final String SAFE_DENIAL =
            "Tool execution denied by server policy";
    private static final String SAFE_UNAVAILABLE =
            "Tool execution unavailable";

    private final TrustedRunContext trustedContext;
    private final ToolPolicy policy;
    private final AtomicBudgetLedger budgets;
    private final AppendOnlyAuditStore audit;
    private final ExecutionIntentLedger intents;
    private final DownstreamDeadlineController deadlines;
    private final OutcomeReconciler reconciler;
    private final ObservationRegistry observations;
    private final ToolCallback delegate;

    PreauthorizedToolCallback(
            TrustedRunContext trustedContext,
            ToolPolicy policy,
            AtomicBudgetLedger budgets,
            AppendOnlyAuditStore audit,
            ExecutionIntentLedger intents,
            DownstreamDeadlineController deadlines,
            OutcomeReconciler reconciler,
            ObservationRegistry observations,
            ToolCallback delegate) {
        this.trustedContext = Objects.requireNonNull(trustedContext);
        this.policy = Objects.requireNonNull(policy);
        this.budgets = Objects.requireNonNull(budgets);
        this.audit = Objects.requireNonNull(audit);
        this.intents = Objects.requireNonNull(intents);
        this.deadlines = Objects.requireNonNull(deadlines);
        this.reconciler = Objects.requireNonNull(reconciler);
        this.observations = Objects.requireNonNull(observations);
        this.delegate = Objects.requireNonNull(delegate);
    }

    @Override
    public ToolDefinition getToolDefinition() {
        return delegate.getToolDefinition();
    }

    @Override
    public ToolMetadata getToolMetadata() {
        return delegate.getToolMetadata();
    }

    @Override
    public String call(String toolInput) {
        return callGuarded(toolInput, null);
    }

    @Override
    public String call(String toolInput, ToolContext toolContext) {
        return callGuarded(toolInput, toolContext);
    }

    private String callGuarded(String toolInput, ToolContext toolContext) {
        ToolDefinition definition = delegate.getToolDefinition();
        // 解析为 closed DTO 并规范化；策略与审计不保存原始 toolInput。
        NormalizedToolMetadata metadata =
                SafeToolArguments.parseAndValidate(definition.name(), toolInput);
        PolicyDecision decision =
                policy.authorize(trustedContext, metadata);
        appendDecisionOrFailClosed(definition, metadata, decision);

        if (!decision.allowedToExecute()) {
            throw denied(definition);
        }

        BudgetDecision budget = budgets.tryReserve(
                trustedContext.runId(),
                trustedContext.clock().instant(),
                metadata.worstCaseUsage());
        if (budget instanceof BudgetDecision.Denied denied) {
            // BUDGET_DECIDED 只含固定 reasonCode；审计失败直接抛出，delegate=0。
            appendBudgetDecisionOrFailClosed(definition, metadata, denied);
            throw denied(definition);
        }

        BudgetDecision.Reserved reservation =
                (BudgetDecision.Reserved) budget;
        try {
            appendBudgetDecisionOrFailClosed(definition, metadata, reservation);
        }
        catch (RuntimeException preExecutionFailure) {
            // delegate 尚未调用；关闭零消费 reservation，不留下悬挂额度。
            budgets.settle(
                    trustedContext.runId(),
                    reservation.reservationId(),
                    UsageDelta.ZERO);
            throw unavailable(definition);
        }

        ExecutionIntentRef intent;
        try {
            // 对不可逆动作这是硬门；actionRef 与 idempotencyRef 均由服务器规范化。
            intent = intents.appendBeforeExecution(
                    trustedContext.runId(),
                    metadata.actionRef(),
                    metadata.idempotencyRef());
            appendExecutionIntentOrFailClosed(definition, metadata, intent);
        }
        catch (RuntimeException preExecutionPersistenceFailure) {
            // 覆盖 audit、intent ledger 和数据库运行时异常；delegate=0。
            // 若 PREPARED intent 已提交，可由 sweeper 幂等关闭，但 reservation
            // 必须在本路径先以零消费结算，不能永久悬挂。
            budgets.settle(
                    trustedContext.runId(),
                    reservation.reservationId(),
                    UsageDelta.ZERO);
            throw unavailable(definition);
        }

        // 保守默认：拿不到真实用量时按 reservation 结算，不能记为零。
        UsageDelta actual = reservation.reserved();
        try {
            ToolTransportOutcome transportOutcome =
                    Observation.createNotStarted(
                                    "agent.tool.execution", observations)
                            // 工具名来自受控注册表且集合有界；参数、结果、tenant 不作标签。
                            .lowCardinalityKeyValue(
                                    "agent.operation", "tool_call")
                            .lowCardinalityKeyValue(
                                    "agent.tool.name", definition.name())
                            .lowCardinalityKeyValue(
                                    "agent.policy.outcome", "ALLOW")
                            .observe(() -> deadlines.callTool(
                                    trustedContext.deadline(),
                                    intent,
                                    delegate,
                                    toolInput,
                                    toolContext));

            if (transportOutcome
                    instanceof ToolTransportOutcome.ConfirmedResult confirmed) {
                actual = metadata.confirmedUsageOrReserved(
                        confirmed.usage(), reservation.reserved());
                recordToolTerminalOrIndeterminate(
                        intent, definition, metadata, IntentState.SUCCEEDED,
                        "CONFIRMED_RESULT", actual);
                return confirmed.result();
            }

            if (transportOutcome
                    instanceof ToolTransportOutcome.DefinitelyNotExecuted
                            notExecuted) {
                actual = metadata.transportUsageOrReserved(
                        notExecuted.usage(), reservation.reserved());
                recordToolTerminalOrIndeterminate(
                        intent, definition, metadata, IntentState.TIMED_OUT,
                        "DEFINITELY_NOT_EXECUTED", actual);
                throw new ToolTimeoutException(
                        "Tool transport confirmed no execution");
            }

            ToolTransportOutcome.OutcomeUnknown unknown =
                    (ToolTransportOutcome.OutcomeUnknown) transportOutcome;
            actual = metadata.conservativeUsageOrReserved(
                    unknown.conservativeUsage(), reservation.reserved());
            // 尤其对不可逆写入，未知绝不是普通 timeout / failure；
            // 先单调标记 INDETERMINATE，再按同一幂等引用查询，绝不重放。
            throw markToolIndeterminateAndEnqueue(
                    intent,
                    "OUTCOME_UNKNOWN",
                    new IllegalStateException(
                            "Tool transport outcome is unknown"));
        }
        catch (IndeterminateToolOutcomeException indeterminate) {
            throw indeterminate; // 外部结果待查；禁止再次执行 delegate。
        }
        catch (ToolTimeoutException timeout) {
            // 只有 transport 已确认 DEFINITELY_NOT_EXECUTED 才会到这里；
            // TIMED_OUT 已记录，不要重复追加终态。
            throw timeout;
        }
        catch (RuntimeException failure) {
            actual = metadata.failureUsageOrReserved(
                    failure, reservation.reserved());
            recordToolTerminalOrIndeterminate(
                    intent, definition, metadata, IntentState.FAILED,
                    "FAILED", actual);
            throw failure;
        }
        finally {
            // settle 只在这一处：success / failure / timeout 均恰好一次。
            // 若网络使 settle 结果未知，可用同 reservationId 幂等重试。
            budgets.settle(
                    trustedContext.runId(),
                    reservation.reservationId(),
                    actual);
        }
    }

            ExecutionIntentRef intent,
            ToolDefinition definition,
            NormalizedToolMetadata metadata,
            IntentState terminalState,
            String outcomeCode,
            UsageDelta usage) {

        }
        catch (RuntimeException terminalPersistenceFailure) {
            // audit append 或 intent terminal mark 任一失败，都不能把已成功的写入
            // 重新分类为业务 FAILED。初始 PREPARED intent 会被 sweeper 扫描。
            throw markToolIndeterminateAndEnqueue(
                    intent,
                    "TERMINAL_PERSISTENCE_UNAVAILABLE",
                    terminalPersistenceFailure);
        }
    }

    private IndeterminateToolOutcomeException
            markToolIndeterminateAndEnqueue(
                    ExecutionIntentRef intent,
                    String reasonCode,
                    RuntimeException cause) {
        // 顺序是治理语义：先尽力单调持久化未知状态，再安排只读对账。
        try {
            intents.mark(intent, IntentState.INDETERMINATE, reasonCode);
        }
        catch (RuntimeException markUnavailable) {
            // Durable PREPARED intent 由 age-based sweeper 扫描。
        }
        try {
            reconciler.enqueueTool(intent, reasonCode);
        }
        catch (RuntimeException queueUnavailable) {
            // PREPARED / INDETERMINATE intent 是兜底；绝不重放 delegate。
        }
        return new IndeterminateToolOutcomeException(
                "Tool outcome requires reconciliation", cause);
    }

    }

关键边界：工具 wrapper 使用实际 ToolDefinition.name()，且策略决定、预算决定、执行意图与对应强制审计发生在 delegate.call(...) 之前；拒绝、预算不足或执行前审计缺失时 delegate 调用必须为零。成功预占后，confirmed、definitely-not-executed、unknown、failure 都共享唯一 finally 结算点；未知用量按 reservation 保守结算，同一 reservation ID 的结算重试必须幂等且不能释放已消费量。工具终态只记录固定结果码、用量和幂等引用。对不可逆动作，PolicyDecision.REQUIRE_APPROVAL 不能在此处被当作允许；只有独立审批服务验证绑定的 proposal hash、主体和时效后，才能构造 ALLOW 上下文。

终态持久化失败不能撤销已发生的世界。若 delegate 返回后，安全终态审计 append 或 intent 状态写入任一失败，不能声称 delegate 为零，也不能因客户端重试再次写入。执行前已持久化的 ExecutionIntentRef 与幂等引用先单调转为 INDETERMINATE，再由对账器只查询外部系统并补记真实终态；若该状态写入也暂时失败，持久的 PREPARED intent 由 sweeper 扫描。模型调用的 intent 与预算 reservation 同样进入待对账队列。公开结果只说明“结果待确认”，禁止猜测成功 / 失败或盲重放。

Deadline 与取消必须到达真实传输层

requireTimeForModelCall() 只能在调用前拒绝明显来不及的工作，捕获异常也不能单独终止一个阻塞的 HTTP 请求。DownstreamDeadlineController 必须把服务器绝对 deadline、执行前持久化的 ExecutionIntentRef 及其幂等引用一起送到真实模型 provider 与工具 HTTP / DB / queue transport；transport 按剩余时间设置 request / read timeout，并在到期时取消连接或异步 Future。仅调用 Future.cancel(true) 或线程 interrupt 不足以保证下游停止。

工具 transport 不能把所有超时都压成一个异常，而要返回三态：CONFIRMED_RESULT 可落 SUCCEEDED；只有可证明请求未到达执行端的 DEFINITELY_NOT_EXECUTED 才可落 TIMED_OUT；连接中断、响应丢失等 OUTCOME_UNKNOWN 必须先落 INDETERMINATE，再按同一幂等引用查询对账，尤其不可重放不可逆写入。三态都在唯一 finally 以已确认或保守用量结算。超时后 Coordinator 不再启动依赖节点，虚拟时钟继续推进时后台 activity 计数必须保持不变。

#练习与验收

动手练习

  1. 数据集：为上面的七类服务台样本各制作至少 5 个脱敏变体，定义 required / optional 约束、知识和工具夹具、风险层与失败原因码；预留事故回放集，不参与 Prompt 调试。
  2. 轨迹评测器：实现从 TrajectoryEvent 到任务成功、引用支持、工具选择、轨迹效率、安全违规、p50 / p95、token 和单位成功成本的聚合；对每个指标写清分母。
  3. 策略门：用 RBAC、ABAC 与上下文策略实现只读状态和建单提案；为无审批、审批过期、tenant 错误和预算不足证明 delegate 调用为零。
  4. 审计：实现 append-only 测试存储、递增 sequence 和摘要链验证；注入 append 失败，证明高风险路径安全失败。扫描事件 JSON，确保不存在 Prompt、arguments、result、Authorization 与异常原文。
  5. 预算：用真实事务或 CAS 实现 AtomicBudgetLedger，并发 20 个分支争用最后 3 个工具额度，断言只产生 3 个 reservation；结算成功、失败和 timeout 成本。
  6. Spring 切片：用 TestObservationRegistry 验证 agent.operation、risk tier 和 policy outcome 为低基数标签；使用 canary secret 证明 Prompt / 工具内容没有进入 Observation。
  7. 红队发布门：运行直接 / 间接注入、越权、tenant、供应链和 denial-of-wallet 套件；任何攻击成功都阻断候选版本，并将修复样本加入离线回归。

验收标准

  • 能解释为什么最终答案评分不足，并从完整轨迹计算任务、事实 / 引用、工具选择、轨迹效率、安全、人工升级、p50 / p95、token、工具 / 模型成本。
  • 离线回归、在线监控、人工 / 模型评审和红队有不同用途、数据与偏差控制；确定性 oracle 优先，模型评审经过人工校准。
  • 威胁模型覆盖直接 / 间接注入、数据外泄、confused deputy、excessive agency、tenant crossing、不安全输出、供应链 / 工具投毒和 denial-of-wallet。
  • RBAC、ABAC 和上下文策略绑定可信主体、tenant、资源、动作、风险、审批和预算；用户 / 检索 / 模型字段不能改变这些值。
  • 不可逆动作先产生不可变提案，再由独立人工批准；审批绑定 proposal hash、版本、主体和时效，合法写入具有幂等键。
  • EvaluationCase、ExpectedConstraint、TrajectoryEvent、PolicyDecision、ExecutionBudget、BudgetDecision 和审计事件不可变，集合防御性复制，决定携带固定原因码。
  • 模型 Advisor 与工具 callback 都在下游调用前做授权、原子预算预占与强制审计，持久化 execution intent，并把 intent / 幂等引用交给真实 transport；工具使用实际工具名。拒绝、预算耗尽、审批缺失或执行前审计缺失时 model / delegate 调用为零；终态审计或 intent 状态写入失败明确返回 INDETERMINATE，按预写 intent / reservation 对账且不盲重放。所有传输终态在唯一 finally 中按实际或保守用量幂等结算。
  • 绝对 deadline 通过 DownstreamDeadlineController 到达真实模型 transport 与工具 HTTP / DB 客户端；工具 transport 明确区分 CONFIRMED_RESULT、DEFINITELY_NOT_EXECUTED 与 OUTCOME_UNKNOWN，只有第二种可记为 TIMED_OUT，第三种进入不可重放的幂等对账。虚拟时钟测试证明取消后后台 activity 不再增加。
  • Micrometer meter 只使用有界低基数标签，不包含 user、tenant、run、ticket、Prompt 或内容；Spring AI 工具参数 / 结果导出显式保持 false。
  • 测试矩阵覆盖注入、间接注入、角色 / 工具越权、tenant 泄露、不安全写、timeout、token / tool / model / cost 预算、Trace 敏感性、审计缺失和模型拒绝。
  • 页面外链安全、标题锚点唯一、八节点图示有等价文字说明，Java 泛型与 Lambda 箭头已正确转义。
